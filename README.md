# Hitung Kalori by Micoco 🥗📱

Aplikasi pemantau kalori dan nutrisi harian berbasis AI untuk iOS dan Android.

## 🌟 Fitur Utama
- **Kalkulator TDEE & BMR:** Menghitung kebutuhan kalori harian presisi berdasarkan BB, TB, Usia, dan Gender.
- **Log Makanan & Minuman Global:** Pencarian makanan lengkap dengan gramasi & detail makronutrisi.
- **AI Food Photo Scanner & Barcode:** Analisis makanan lewat kamera atau scan barcode kemasan.
- **Smart Meal Suggestion:** Rekomendasi menu sehat berdasarkan sisa kuota kalori harian.
- **Water Tracker:** Pengingat dan pelacak asupan air harian.
- **Meal Prep / Menu Favorit:** Catat menu rutin hanya dengan satu klik.

## 🛠 Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend & Auth:** Firebase (Google Sign-In, Cloud Firestore)
- **Monetisasi:** RevenueCat (In-App Subscription) & Google AdMob
- **AI & Data:** Multimodal AI Vision API & Global Food Database API
